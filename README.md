# growth-systems

Growth is infrastructure. Most teams treat it as a campaign calendar. The compounding advantage comes from building systems that connect channels, share experiment memory, and make learnings portable across cycles. Everything in this repo is a tool or artifact that came out of that approach applied to a real problem.

Two tools are live. Two research documents are in `/research`. The thinking behind all of it is in [PHILOSOPHY.md](./PHILOSOPHY.md).

---

## Tools

### [Growth OS](https://github.com/cristobaldupuis/growth-os) — [Live app](https://cristobaldupuis.github.io/growth-os/)

A growth execution framework for multi-brand ecommerce portfolios. Initiative lifecycle management, a two-proportion z-test sample size calculator, statistical significance tracking, incrementality documentation, ICE scoring, and AI-assisted learning synthesis across closed initiatives. Built in React + Vite with the Anthropic Claude API via BYOK.

It started as a reaction to watching growth teams run experiments in disconnected spreadsheets with no memory. This does.

### [deepstint](https://github.com/cristobaldupuis/deepstint) — [Live app](https://app.deepstint.com)

A Pomodoro and time-tracking app built around one constraint: it cannot get in its own way. Type a task, hit start, you are working. Partner/category/task hierarchy, daily priorities, session logging, end-of-day reflection. Built in React + Vite with Supabase and Cloudflare Pages.
